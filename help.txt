# Controls:
  ### General
  [F4]         > Exit program

  [Tab]        > Next tab
  [F5]         > File tab
  [F6]         > Editor tab
  [F7]         > Note editor tab
  [F8]         > Help tab
  Also, tabs are clickable.

  ### File tab
  [Up]         > Select up
  [Down]       > Select down
  [Enter]      > Open selected file/directory
  [Backspace]  > Open parent directory
